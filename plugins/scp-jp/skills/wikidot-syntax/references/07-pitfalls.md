## パーサ・記法

| # | 事象 | 対処 |
|---|---|---|
| 1 | `>` の直後に半角スペースが無いと引用にならない | `> 本文`。空行も `>` ＋スペース |
| 2 | `[[div]]` `[[/div]]` `[[collapsible]]` `[[code]]` `[[html]]` `[[note]]` `[[gallery]]` `[[<]]`〜`[[==]]` は**単独行**必須。行末のスペースすら不可 | タグ行に何も足さない |
| 3 | `[[include]]` は `[[code]]` の中でもパースされる | 行頭に半角スペースを1つ |
| 4 | `====`（4つ以上）は単独行だとセクション区切りになる。意図せず本文が分断される | `@@====@@` または末尾にスペース（code内は末尾スペースのみ有効） |
| 5 | 空行を連打しても1行に潰される | ` _`（スペース＋アンダースコア）を並べる |
| 6 | ` _` の後ろに文字を置くと効かない | 行末は必ず `_` で終える |
| 7 | em dash `--` は前後にスペースが無いと変換されない | ` -- ` |
| 8 | ユーザー定義 `id` は出力で `u-` が付く | CSS もアンカーも `u-` 込みで書く |
| 9 | div/span で使える属性は `id` `class` `style` `data-*` のみ | それ以外はHTMLブロックで |
| 10 | `[[/div]]` は対応が緩く、閉じ忘れてもエラーにならず DOM だけ壊れる | 閉じ忘れに注意。`[!-- start/end --]` でマーキング |
| 11 | `[[div]]` を閉じ忘れる／`position:absolute` を誤指定するとページが崩壊し、編集ボタンも押せなくなる | **`…/page/norender/true`** で開くか、DevTools で一時的に CSS を打ち消して編集リンクを掘り出す |
| 12 | `[[collapsible]]` はネスト不可 | Colmod（`component:coltop` / `colend`）を使う |
| 13 | `[[tabview]]` は TOC・アンカーリンク・ブラウザの戻るを壊す。タブ内見出しに TOC から飛べない。タブ内リンクから戻ると必ず最初のタブになる。素直なネストも不可 | 重要な見出しはタブの外に置く |
| 14 | `[[/tabview]]` の直前が `[[/tab]]` でないと構文エラー | 逆にこれを利用したフッター技がある（06 A-7） |
| 15 | tabview 内 div の id はコンパイルのたびに変わる | id 決め打ちの CSS/JS を書かない |
| 16 | 日本語のページ名（URL）は作れない | URL は英数字、タイトルだけ日本語にする |
| 17 | `_` 始まりのページは NewPage モジュールで作れない | URL 直打ちで作成 |
| 18 | `[[embedaudio]]` の公式サンプルは Flash 前提で動かない | `[[include :snippets:html5player]]` |
| 19 | `[[iframe]]` の許可属性は `frameborder` `align` `height` `width` `scrolling` `class` `style` のみ | それ以外が要るなら `[[embed]]` |
| 20 | `[[file /filename]]`（先頭スラッシュ）は start ページの添付を意味する | 意図しないなら先頭スラッシュを付けない |

## モジュール

| # | 事象 | 対処 |
|---|---|---|
| 21 | モジュール本文に `[[code]]` / `[[html]]` を入れると**モジュールごと動かない** | `[[%%content{0}%%html]]` 技（06 A-1）。ただし `separate="yes"` 必須 |
| 22 | ほとんどのモジュールは ListPages の中に入れられない | 同上、または設計を変える |
| 23 | `separate="yes"/"no"` でコンパイル単位が変わり、`[[iftags]]` の参照先と `[[image :first]]` の可否が変わる | 用途に応じて明示指定する |
| 24 | 同一ページに複数の ListPages を置くと URL 引数が衝突する（片方の「次へ」が両方に効く） | `urlAttrPrefix` を個別に付ける |
| 25 | 評価タイプ（`+` / `+/-` / stars）が異なるカテゴリを跨いで rating で選択・整列すると壊れる | 同じ評価モードのカテゴリに限定する |
| 26 | RSS 出力は `created_at` セレクタを無視する | 別手段で絞る |
| 27 | ListPages はページを著しく重くする。1ページに複数は非推奨 | 減らす／キャッシュ前提で設計する |
| 28 | `order="プロパティ asc"` は不正。黙って既定順（`created_at desc`）に落ちる | 昇順は無印、降順は ` desc`、`desc desc` で昇順に戻せる |
| 29 | `perPage` の既定は20、最大250 | 一覧が途中で切れたら疑う |
| 30 | 日付セレクタは**サイトのローカル時刻ではなく UTC** | JST とのズレを考慮 |
| 31 | ListPages が複数ページにマッチすると本文がその件数だけ複製される。HTMLブロックも複製される | 集約したいなら iframe 間通信が必要 |
| 32 | `%%rating%%` はページ読み込み時点の値。投票直後には反映されない | リロード前提の演出にする |
| 33 | `%%link%%` はカスタムドメインでは機能しない | `%%fullname%%` から組み立てる |
| 34 | ListUsers は匿名ユーザーに対して何も出力しない | 逆用してゲスト用文面を出せる（06 B-3） |

## HTMLブロック・iframe

| # | 事象 | 対処 |
|---|---|---|
| 35 | HTMLブロックは別ドメインの iframe。親の DOM/CSS/スクロールに触れない | postMessage で通信 |
| 36 | HTMLブロックは中身の高さに自動追従するが、**中に `<iframe>` を入れるとその高さは計測されず150px固定** | 素の `[[iframe]]` ＋自前の高さ通知（06 C-4） |
| 37 | 折り畳みの中のHTMLブロックは、開くまで高さが確定しない | `isHTMLblockHide = true` 系の監視、または開閉時に再計算 |
| 38 | `<html>` / `<body>` にスタイルを当てられない | 全体を `<div style="…">` で包む |
| 39 | サインアウト状態では未知の iframe が3つ挿入され、`frames` のインデックスがずれる。Edge/Firefox ではサインアウト時に postMessage が失敗する | フレーム番号を決め打ちせず自分のインデックスを探索する。非サインイン時は `try/catch` でフォールバック |
| 40 | 同一 URL に対して自動高さ調整 iframe を2つ以上置くとバグる | URL にキャッシュ破棄用のクエリを付けるか1つに絞る |
| 41 | HTMLブロック内では `<script src>` に直書きしたコードがアンチウイルスに弾かれることがある | `wdfiles.com/local--code/…` 経由の script src にする |
| 42 | CSS の縦書きはブラウザの縦幅計算を頻繁に壊す | 高さを固定する |

## 一般

| # | 事象 | 対処 |
|---|---|---|
| 57 | `[[#expr]]` / `[[#ifexpr]]` の式は256文字まで。関数は `abs` `min` `max` のみ | 複雑な計算は諦めるか JS へ |
| 58 | include の同名引数は「下が先に解決される」 | デフォルト値の実装に使えるが、意図しない上書きに注意 |
| 59 | インクルード元の添付画像は `[[image included-page/file.jpg]]` と書く | ページ名を省略すると呼び出し側のページを探しに行く |
| 60 | 検索のタグ検索は性能上の理由で無効化されている | ListPages の `tags` セレクタを使う |
| 61 | 同じサイトのページでも `:<自サイト名>:` を付けて include すると、サイト外 include として扱われる。サイト外 include を許可していないサイトではエラーになる | 同じサイトのページはサイト名を付けずに `[[include ページ名]]` と書く |
| 62 | `[[module CSS]]` の本文の `&` は `&amp;` のまま `<style>` に出力され、`@import url()` のクエリが壊れる | `&` を `\26 `（後ろに半角空白）で書く（03 §3） |
| 63 | ライブテンプレートが include するページを変えても、テンプレートを使う各ページの表示は順に再描画されるので、ページ数が多いと反映まで数十分かかる | 保存直後の表示で失敗と判断せず、時間をおいて複数のページで確認する |
